CacheControl

parses Cache-Control header values (RFC 7234 §5.2) into a map of lower-cased directive names to their values, with convenience accessors for the common directives.

directive

defn

(Fn [(Ref (Map String a) b), (Ref String c)] (Maybe a)) 

                        (directive m name)

looks up directive name (case-insensitive), returning its value as (Maybe String). A present valueless directive yields (Just @"").

has?

defn

(Fn [(Ref (Map String a) b), (Ref String c)] Bool) 

                        (has? m name)

whether directive name (case-insensitive) is present.

max-age

defn

                        (max-age m)

the max-age delta-seconds as (Maybe Int), when present and numeric.

parse

defn

(Fn [(Ref String a)] (Map String String)) 

                        (parse s)

parses a Cache-Control header value into a map from lower-cased directive names to values. A valueless directive (e.g. no-cache) maps to the empty string; a quoted value has its surrounding quotes removed. Empty segments are ignored, so an empty header yields an empty map.
