Form

provides URL-encoded form body parsing.

(match (Form.parse "name=carp&version=1")
  (Result.Success m) (println* &(Map.get &m "name"))
  (Result.Error e) (IO.errorln &e))

parse

defn

(Fn [(Ref String a)] (Result (Map String String) b)) 

                        (parse s)

parses a URL-encoded form body into a (Map String String). Keys and values are percent-decoded.
